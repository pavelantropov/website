# Сайт-визитка Павла Антропова

Одностраничный сайт на ASP.NET Core.

## Локальный запуск

```powershell
dotnet run --project src/PavelAntropov.Website
```

Откройте адрес, показанный в консоли (обычно `http://localhost:5000`).

## Docker

```powershell
docker compose up --build
```

Сайт будет доступен по адресу `http://localhost:5000`.
